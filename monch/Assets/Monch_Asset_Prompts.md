# Monch Mascot Asset Generation Prompts

## Character Reference
**Inspiration:** Totodile × Gible — a small, cute crocodilian/dragon creature with a BIG expressive mouth.  
**Name Origin:** "Monch" = "Munch" = chompy energy!

---

## Base Character Description
> Use this as a prefix for ALL prompts to maintain consistency.

**Monch Base:**
```
A small, cute crocodilian/dragon mascot character named "Monch" inspired by Totodile and Gible from Pokémon. Key features:
- BIG expressive mouth (the defining feature) - wide, can show friendly teeth
- Compact rounded body, top-heavy (big head, small body)
- Stubby little arms and legs
- Small dorsal fin or head ridge for silhouette distinction
- Short stubby tail with accent shape
- Large round expressive eyes above the snout
- Teal/aqua body color with cream/pale yellow belly
- Friendly and approachable despite being chompy
```

## Export Specifications

### In-App Assets
| Setting | Value |
|---------|-------|
| Source Resolution | 512×512px minimum |
| Export Format | Lottie JSON (animated) or PNG@3x (static) |
| Color Profile | sRGB |
| Background | Transparent |

### 8-Bit Assets  
| Setting | Value |
|---------|-------|
| Base Resolution | 32×32px |
| Export Sizes | 32px (@1x), 64px (@2x), 96px (@3x) |
| Format | PNG with transparency |
| Color Limit | 16 colors max per sprite |
| Background | Transparent |
